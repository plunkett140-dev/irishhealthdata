# Editorial Voice — Reference Canon

Extends Technical Design Document Section 3, "Editorial standards" (Fact / Inference / Opinion). This document is about *how* to write once that discipline is already in place — the canon of writers whose specific techniques this project deliberately borrows from, and what exactly to take from each.

This is a living reference. Add to it. The point is to make voice a documented, arguable decision like everything else in this project — not a tacit house style nobody could describe if asked.

---

## John Burn-Murdoch (Financial Times)

**The core lesson: the chart is the argument, not an illustration of one.**

- Lead with the visual. Prose exists to sharpen what's already visible, not re-describe it.
- Avoid throat-clearing openers ("In recent years, much attention has been paid to..."). Start at the finding.
- Captions do real work — the one number or comparison that isn't obvious from the axis alone.
- Pre-empt the skeptical reader's objection in-line, briefly, rather than ignoring it or relegating it to a footnote nobody reads.
- Comfortable showing a chart that complicates the headline finding, not just ones that support it.

## Sinéad O'Sullivan

**The core lesson: numbers-first, willing to hold an uncomfortable conclusion if the data actually supports it.**

- Don't soften a real finding to seem balanced if the finding itself is genuinely one-sided.
- Specificity over vibes — a contrarian take earns its place by citing the exact figure, not a general impression.

## Ken Early (Irish Times)

**The core lesson: start concrete and specific, then widen the lens — never lose the specific detail that earned the bigger claim.**

- A single match, a single hospital, a single patient's specific numbers can be a legitimate entry point into a national or systemic story, provided the piece keeps returning to that concrete anchor rather than drifting into pure abstraction.
- Dry wit is fine; distortion for effect is not.

## David McWilliams

**The core lesson: find one vivid, memorable framing device per piece.**

- Big structural forces need a human-scale analogy to actually land.
- **Use with more caution on this project than the others** — McWilliams' style leans narrative/persuasive in a way that sits closer to the Opinion category than this project's Fact/Inference discipline is comfortable with by default. Borrow the instinct for a strong framing device; don't borrow the rhetorical push toward a conclusion.

## Michael Lewis

**The core lesson: find the one person whose specific decisions make an abstract system legible.**

- Most relevant for long-form, investigative pieces — a single clinician, administrator, or patient's documented experience anchoring a systemic finding.
- Not the default mode for short data-led pieces (see Burn-Murdoch instead); reserve for when the project does a genuinely long-form feature.

---

## House synthesis for this project

Given the Fact/Inference/Opinion discipline already established, the working default is: **Burn-Murdoch structure (chart first, tight explanatory prose), Ken Early's concrete-to-general movement (open on one hospital or one number, not a national abstraction), O'Sullivan's willingness to state an uncomfortable finding plainly.** McWilliams and Lewis are reserve techniques for pieces that specifically call for a narrative framing device or a long-form investigative structure — not the default for a standard data piece.

*Future Me Test: if every article ends up sounding identical, this canon has calcified into a formula rather than a set of tools — revisit and loosen it.*
